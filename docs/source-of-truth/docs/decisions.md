# Besluiten

Statusdatum: 2026-10-15. Fase 2 publiceert alleen de GitHub-basis en documentatie. Geen serverwijziging, deployment, applicatiemigratie of back-upactivatie. Gewenste vervolgstappen zijn geen uitgevoerde configuratie.

Vier centrale infrastructuurrepositories als uiteindelijke private eindtoestand; één eigenaar per configuratieonderdeel. Server2-platform en de bestaande Flux-bronpaden blijven behouden. Server1-configuratie wordt niet opnieuw uitgevonden. Secrets blijven buiten Git, behalve passende versleutelde configuratie met onafhankelijke herstelkeys.

Deze fase machtigt twee nieuwe private repos, hernoeming van homelab-ops met behoud van historie/keys/paden, en documentatiepublicatie. Bestaande repos worden nu niet private gemaakt of verwijderd; applicaties worden niet verplaatst. Backup v2 blijft een apart bevroren reviewtraject.
